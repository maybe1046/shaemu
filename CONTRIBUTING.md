# Contributing

These guides are meant to grow as players correct them. Changes are welcome.

## How to help

- **Fix a number or rule.** If something marked **⚠ verify** is wrong for your server, replace it. Say which server it applies to (Lakebane or Shadowbane: Resurgence) and where you confirmed it: a patch note, the calculator, a Discord post, or your own testing.
- **Add a guide.** Put new guides in `guides/` using the next number, and add a row to the table in `README.md`.
- **Keep it player-focused.** Stick to practical advice, clear steps, and short tables.

## Style

- Use one `#` heading per file, with `##` and `###` for sections.
- Put **⚠ verify** after any claim that depends on server tuning or that you haven't tested.
- Prefer tables for comparisons such as races and classes.
- Link to sources when you have them.
